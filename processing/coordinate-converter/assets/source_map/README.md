# 2026-09-24 灰线道路地图

`source_map.png` 原样复制自用户指定的
`/mnt/chengchangxu/projects/visual_navigation_e2e/data/source_map.png`（2192×1642）。
用户确认该图沿用旧手绘图的位置关系，是同一布局放大后的描画，因而复用旧 JPG↔P_map 道路配对。
原始 PNG、旧 JPG、配对道路、旁侧编辑器标注的 SHA-256 与三个道路擦除矩形记在
`registration.json`。编辑器标注用于记录来源，不提供世界坐标配准。

新旧像素中心换算为 `source_xy=(jpg_xy+0.5)*[2192/1441,1642/1079]-0.5`，
再将新图逆时针旋转 90°，不缩放、不插值。新 PNG 栅格 `(u,v)` 对应最终左下像素 `(v,u)`。
图像中黑色 0 为建筑，灰色 192 为道路，白色 255 为背景；不把建筑内部白色当成道路。
在已配对主环路/支路上复用弧长映射，关闭所有端点吸附；只允许最多 2 px 的栅格角点校正，
无法落到灰线的旧入口不另找一条道路来吸附。新画而未配对的道路尚无世界坐标标注，不能据图猜测。

该注册沿用旧标定误差，不是新的实测配准。对齐图不存在统一精确米/像素比例；元数据仅给出名义尺度，
`resolution_m=null`。改变地图布局或比例后须重新核对注册，不能直接替换 PNG 绕过哈希校验。
